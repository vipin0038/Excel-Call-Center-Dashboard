#  Call Center Dashboard – Excel Project

This project is a fully interactive **Call Center Performance Dashboard** built using **Microsoft Excel**.  
It visualizes key call-center metrics, trends, and representative performance using clean and professional charts.

---

##  Dashboard Overview

The dashboard provides a complete view of call-center performance, including:

### **Key Metrics**
- **Total Calls:** 1,000  
- **Total Amount:** $96,623  
- **Total Duration:** 89,850 seconds  
- **Average Rating:** 3.9  
- **Happy Callers:** 307  

---

##  Visual Features

### **1. Call Trend Chart**
A monthly line graph showing call volume changes from January to December.

### **2. Day-Wise Call Distribution**
Bar chart showing the number of calls received on each day of the week.

### **3. Female vs Male Callers**
A demographic comparison chart for the cities:
- Cincinnati  
- Cleveland  
- Columbus  

### **4. Rating Distribution**
Histogram showing the distribution of customer ratings from 1 to 5.

### **5. Representative Performance**
Breakdown of:
- Calls handled by each representative (R01–R05)  
- Amount generated by each representative  

### **6. City & Customer Performance Table**
A fully dynamic table displaying:
- Customer IDs  
- Amount generated per representative  
- Total revenue per customer  
- Grouped by Cincinnati, Cleveland, and Columbus
